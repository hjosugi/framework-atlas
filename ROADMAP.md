# Roadmap

## Phase 1 — reproducible foundation

- Curated cross-language catalog
- GitHub topic snapshots
- Evidence-aware relationship graph
- Searchable static site
- Issue drafts for missing research

## Phase 2 — source hardening

- Add primary-source evidence to every deep profile
- Resolve ambiguous repository identity and project renames
- Add release and maintenance-history snapshots
- Add maintainership and governance fields

## Phase 3 — design comparison

- Architecture decision matrix
- Migration and succession maps
- Benchmark-methodology registry
- Failure and abandonment case studies
- “Design a new framework” decision workbook

## Phase 4 — community maintenance

- Language/domain maintainers
- Automated stale-evidence checks
- Review queues for candidate repositories
- Periodic versioned dataset releases
