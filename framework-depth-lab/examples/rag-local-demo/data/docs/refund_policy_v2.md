# 対象条件

年間サブスクリプションは、購入日から30日以内に申請した場合のみ返金できます。
30日を過ぎた申請は返金の対象外です。

月額サブスクリプションは返金の対象外です。日割り計算も行いません。

# 処理時間

承認された返金は、5〜7営業日以内に元の支払い方法へ返金されます。
クレジットカード会社の締め日によっては、明細への反映が翌月になる場合があります。

# 申請方法

返金の申請は、アカウント設定の「請求」ページから行います。
サポート窓口へのメールでは受け付けていません。
