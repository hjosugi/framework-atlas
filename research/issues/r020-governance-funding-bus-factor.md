# Governance、funding、bus factor を記録する

## 背景

foundation、single vendor、independent maintainer、dual license、sponsor model を framework adoption risk として整理する。

## 完了条件

- [ ] React Foundation 等の current governance を確認
- [ ] organization と trademark owner を分離
- [ ] 個人への推測を避ける

## Evidence rule

- 直接影響は公式文書・作者発言・package/source dependency がある場合だけ確定する。
- 類似だけの場合は `needs-evidence` または `design-relative` のままにする。
- 変更した relation には confidence、verification、source URL を付ける。

## 主な変更対象

- `data/frameworks.json`
- `data/relations.json` または `data/families.json`
- `profiles/`、`history/`、`research/`
